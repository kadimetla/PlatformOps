# build-agui-a2ui-transport

FastAPI AG-UI/SSE backend transport (`transports/http.py`) and the A2UI dynamic-rendering adapter (`interaction/a2ui.py`) that lets a browser chat app drive `PlatformOpsHarness` end to end -- chat in, clarify via dynamically-rendered A2UI components if needed, see the resolved (or unsupported) route. Milestone 1 of the web chat app: see `docs/WEB_CHAT_APP.md`.
